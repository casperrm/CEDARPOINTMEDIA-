# CEDARPOINTMEDIA-

## Hamed Translator

An everyday voice translator between **English · العربية · 中文 · Français**,
done by **Mhmd Rmaity**.

**Live: https://casperrm.github.io/CEDARPOINTMEDIA-/translator/**

Open it on the phone and use *Add to home screen* to keep it like an
application. The source of the page is in [`translator/`](translator/), and
[`translator/README.md`](translator/README.md) explains how it works.

The website is published automatically by
[`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every push to
`main`.
